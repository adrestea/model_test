## 指标口径

- **CER** = (错认 + 漏提 + 多提) / GT 字数，按字符级编辑距离拆解，越低越好。
- **完整率** = 1 − 漏提率 − 错认率，对应“文字尽可能提全”的业务目标。
- **漏提率** / **多提率** / **错认率** 分别对应 OCR 老毛病与大模型幻觉。
- **行级 F1** 按归一化行文本集合匹配，免疫行序差异；**定位 IoU** 只在有 box 时计算。
- 成本在 run.json 内为 USD，本文按 1 USD = 7.2 CNY 折算。
